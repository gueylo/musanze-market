# AI Use Declaration

AI assistance was used to help scaffold and refine this React Native Expo prototype, including screen layout suggestions, TypeScript implementation support, debugging guidance, and documentation drafting.

All project requirements, fictional inspection data, visual choices, and final testing decisions were reviewed by the project team. No real personal data is included in the application.

The local market photographs in `assets/` are used only for this university prototype. The Musanze volcano splash image was added as a visual reference asset.
